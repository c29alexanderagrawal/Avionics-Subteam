# Glossary

Acronyms and terms used in the avionics requirements. Add new ones in alphabetical order.

| Term | Meaning |
|---|---|
| AGL | Above ground level. Altitude measured from the launch site, not sea level. |
| Apogee | The highest point of the rocket's flight. |
| CAN | Controller Area Network. A robust serial bus for connecting multiple devices. |
| Continuity check | A test that confirms an e-match circuit is complete before launch. |
| COTS | Commercial off-the-shelf. A bought part or product, not one we designed. |
| Drogue | The small parachute deployed at or near apogee to slow and stabilize descent. |
| E-match | Electric match. The igniter that sets off a pyrotechnic charge. |
| FAR-OUT | The competition Blue Horizon Rocketry is targeting. See the FAR-OUT Rules & Requirements document. |
| FC | Flight computer. |
| GNSS / GPS | Global Navigation Satellite System / Global Positioning System. Satellite positioning. |
| I²C | Inter-Integrated Circuit. A two-wire serial bus common on sensors. |
| IMU | Inertial measurement unit. Measures acceleration and rotation rate. |
| LiPo | Lithium polymer battery. |
| Main | The larger parachute deployed at low altitude for landing. |
| MCU | Microcontroller unit. |
| PCB | Printed circuit board. |
| RF | Radio frequency. |
| SPI | Serial Peripheral Interface. A fast four-wire serial bus. |
| SRAD | Student researched and designed. Hardware or software the team built itself. |
| TBD | To be determined. |
| UART | Universal asynchronous receiver-transmitter. A simple two-wire serial link. |
